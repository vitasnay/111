# Colorize Studio

Colorize Studio - это приложение для автоматической колоризации черно-белых изображений с использованием GPU-ускорения.

## Возможности

- Автоматическая колоризация черно-белых изображений
- Поддержка пакетной обработки
- GPU-ускорение с использованием CUDA
- Современный графический интерфейс на Qt6
- Поддержка различных форматов изображений
- Мультиязычный интерфейс

## Системные требования

### Windows
- Windows 10 или новее
- CUDA Toolkit 11.0 или новее
- Qt6 6.2.0 или новее
- Visual Studio 2019 или новее
- CMake 3.15 или новее

### Linux
- Ubuntu 20.04 или новее
- CUDA Toolkit 11.0 или новее
- Qt6 6.2.0 или новее
- GCC 9.0 или новее
- CMake 3.15 или новее

### macOS
- macOS 10.15 (Catalina) или новее
- CUDA Toolkit 11.0 или новее
- Qt6 6.2.0 или новее
- Xcode 12.0 или новее
- CMake 3.15 или новее

## Установка

### Windows
1. Убедитесь, что у вас установлены все необходимые зависимости:
   ```powershell
   .\install_dependencies.ps1
   ```

2. Соберите проект:
   ```powershell
   mkdir build
   cd build
   cmake ..
   cmake --build . --config Release
   ```

### Linux
1. Установите зависимости:
   ```bash
   sudo ./install_dependencies.sh
   ```

2. Соберите проект:
   ```bash
   mkdir build
   cd build
   cmake ..
   make -j$(nproc)
   ```

### macOS
1. Установите зависимости:
   ```bash
   ./install_dependencies_macos.sh
   ```

2. Соберите проект:
   ```bash
   mkdir build
   cd build
   cmake ..
   make -j$(sysctl -n hw.ncpu)
   ```

## Использование

1. Запустите приложение
2. Выберите изображение или папку с изображениями
3. Настройте параметры обработки
4. Нажмите "Обработать"

## Поддержка GPU

Приложение автоматически определяет наличие GPU и его возможности. Если GPU недоступен или не соответствует требованиям, будет использован CPU-режим.

### Требования к GPU
- Архитектура CUDA 5.0 или новее
- Минимум 2 ГБ видеопамяти
- Поддержка CUDA 11.0 или новее
